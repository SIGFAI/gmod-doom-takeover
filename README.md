# Doom Takeover

**Garry's Mod** × Doom · visual · idea by the team

Bring Doom into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I put Doom into Garry's Mod: marines, imps, a 3D cacodemon, exploding barrels and a BFG that zaps a whole pack at once.

## Install

Unzip the mod folder into garrysmod/addons/ as its own folder, start Sandbox on any map, and the Doom look, demons, barrels and the BFG 9000 (in the Weapons tab) are there.
